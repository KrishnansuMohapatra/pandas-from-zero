# 🐼 Pandas From Zero

A beginner-friendly Pandas learning series built by **KrishnansuCodes**.

The goal is simple: learn Pandas by actually working with data instead of only memorizing functions.

## 📚 Learning Path

```text
01 Introduction
02 Reading CSV Files
03 Selecting Data
04 Filtering Data
05 Aggregation
06 GroupBy
07 Data Cleaning Project
08 Final Sales Analysis
```

## 🧠 What This Repository Covers

- Loading CSV data
- Selecting rows and columns
- Filtering data with conditions
- Aggregating data with statistics
- Grouping and comparing data
- Cleaning messy datasets
- Finding patterns in sales data
- Turning numbers into simple business insights

## 🛠️ How I Practice

Each lesson uses code, a small dataset and practice instead of only theory.

The projects combine the lessons so I can move from:

**learning syntax → solving problems → analyzing data**

## 🚀 Projects

### 🛒 Sales Investigation
Find the biggest sale and identify the product and city behind it.

### 🧹 Sales Data Cleaning
Inspect and clean a deliberately messy sales dataset.

### 📊 E-Commerce Sales Analysis
Combine inspection, aggregation, GroupBy, product, city, category and monthly analysis.

## 🎯 Goal

I'm building this repository from beginner level and improving it as I learn.

The goal is not to collect every Pandas function. It is to understand **when and why to use Pandas to answer questions about data.**
